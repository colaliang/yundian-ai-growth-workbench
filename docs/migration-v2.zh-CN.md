# contractVersion 2 迁移、更新与能力边界

工作台发行版本保持0.15.0，数据 schemaVersion=3、contractVersion=2。版本号不代表已发布或已部署。迁移仅用于客户明确选择的授权目录；演练用临时目录。

## 迁移和回滚

`migrateWorkspace` 完整预检旧JSON、任务引用和成果路径后再写入。坏JSON、越界或非法引用使迁移停止，原字节和目录树不变。有效迁移在 `growth-workspace/migration-backups/<编号>/` 保存完整旧目录，保留旧任务、成果及AI历史草稿原文，草稿仍待核验。重复迁移不重复写，启动和读回验证客户workspaceId、任务数、成果内容及配置。

更新前创建完整本地快照、检查Git改动及客户技能；新代码在独立目录编译并验证。不要自动git pull/reset、覆盖定制或按时间戳覆盖冲突。技能manifest按版本和SHA-256比较，冲突保留客户版本及新官方候选，再显式选择。回滚使用迁移前快照恢复并回到旧代码；先检查实际外部定时任务，没有可核验暂停能力则提示需宿主处理。默认不删除远端备份。

## 当前实现和缺口

| 能力 | 当前验证范围 | 外部现场要求 |
|---|---|---|
| 知识/任务/真实文件回执/哈希验收/反馈下一轮 | 本地真实目录、CLI、HTTP及浏览器 | WorkBuddy实际项目执行和技能加载仍须单独验证 |
| 技能包 | 独立ZIP+总包、文件manifest、工作树标记 | WorkBuddy客户端导入格式和加载结果 |
| 每日清单 | 实际任务、资料缺口及反馈规则，源轮次保留 | 不声称业务获客效果 |
| 原生定时 | 配置、指令、去重批次与结果校验 | 无原生API；创建/暂停/查询未实现，手填ID不启用 |
| 备份 | 本地二进制快照、校验与冲突保留 | 在线认证隔离存储未接入、默认关闭 |
| 公共监听 | 公共HTTP绑定 | 不是认证私有托管；禁止客户资料放入演示 |
| 专家与陪跑 | 已确认联系方式、模块映射、真实任务进度 | 没有支付、订单或资料自动授权 |

## 快速本地验收

`npm test`覆盖全部TypeScript测试，`npm run typecheck`、`npm run build`编译完整图，`npm run package:skills`输出工作树包。用临时客户目录启动 `node server.js --root <临时目录> --port <独立端口>`；检查HTTP页面、知识文件读回、创建/复制不误显示执行、实际文件回执与验收、文件变化失效、销售反馈下一轮。打开窄屏检查横向溢出和交互错误。不要将这些结果当作当前公网演示已更新。
